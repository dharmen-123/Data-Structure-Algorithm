
        // ******* STRING ******** //

A string in C++ is a sequence of characters used to represent text.
C++ provides two ways to handle strings:

* C-style strings → character arrays (char str[] = "Hello";)
* C++ STL string class → more powerful, flexible, and safer (string str = "Hello";)

    ** Key Features **

 * Dynamic size (can grow/shrink).
 * Rich set of built-in functions.
 * Easy concatenation, comparison, and manipulation.
 * Defined in <string> header.

🔹 Declaration
A string is declared using the string class from <string> header.
    #include <string>
    string str;        // empty string
    string name;       // declaration without initialization

🔹 Initialization
There are multiple ways to initialize a string:
string s1 = "Hello";          // direct initialization
string s2("World");           // constructor initialization
string s3 = s1;               // copy initialization
string s4(5, 'x');            // "xxxxx" (repeat character)
string s5 = {'A','B','C'};    // "ABC"

🔹 Input and Output
string str;
cin >> str;                   // reads single word (stops at space)
getline(cin, str);            // reads full line including spaces
cout << str;                  // prints string

    *** Null Character ('\0') ***

* The null character ('\0') is a special character with ASCII value 0.
* It is used to terminate C-style strings (character arrays).
* It tells the compiler and runtime: “This is the end of the string.”
* Without '\0', the program won’t know where the string ends and may read garbage values beyond the intended length.
